# Shape Snap

グリッドに吸着する四角・円・多角形を、クリックと単独キーだけで置いて、動かして、変形して、書き出すブラウザ用の描画ツールです。
ドラッグ、同時押し（Shift・Ctrl・Alt）、ダブルクリック、ホバーだけで使う操作は一つもありません。

## 起動

```
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。作品は自動で保存され、リロードしても戻ります。

## できること

- 四角・円・多角形をカーソルの位置（グリッドの点）に置く
- 図形をクリックで選び、何もない点をクリックするとそこへ動く
- 辺の中央のつまみをクリックでつかみ、次のクリックか矢印で動かして広げ縮める
- 多角形の辺を動かすと「自由な形」になる（Z で戻せる）
- 重なった図形は、同じ点をもう一度クリックすると奥のものに切り替わる
- 設定パネルで位置・大きさ・回転・色・線を変える
- SVG、PNG、作業ファイル（JSON）に書き出す

## キー

| キー | はたらき |
|---|---|
| R / C / P | 四角 / 円 / 多角形を置く |
| Q / E | 前の図形 / 次の図形を選ぶ |
| W | 次のつまみをつかむ |
| M | 複数選択の入・切 |
| 矢印 | 選んだ図形（つかんだつまみ）を 1 グリッド動かす。何も選んでいないときは表示を動かす |
| Space | カーソルの位置へ動かす |
| F / B | 一つ手前へ / 一つ奥へ |
| D | 複製 |
| Delete / Backspace | 消す |
| Z / Y | 取り消す / やり直す |
| H / K / O | 隠す・出す / ロック / ソロ |
| 0 | 全体表示 |
| 1 / 2 | グリッドを細かく / 粗く |
| Tab | 操作する場所（キャンバス・図形リスト・設定）を切り替える |
| Esc / 右クリック | つかむのをやめる、選択を外す |
| マウスのホイール | 拡大・縮小（設定パネルの上では値の増減） |

数値の欄は、クリックして数字を打ち、Enter で決めます。

## テスト

```
npm run typecheck   # 型の検査
npm test            # 単体テスト（Vitest）
npm run build       # 型の検査 + 本番ビルド
npm run e2e         # ブラウザでの通しテスト（Playwright、開発サーバーを自動で起動）
```

`tests/promises.test.ts` と `e2e/promises.spec.ts` が、操作の約束（ドラッグ・同時押しを使わない、ボタンと行は高さ 40px 以上、
ページ全体がスクロールしない、明るい表示と暗い表示のどちらでも文字が読める）を守っているかを確かめます。
