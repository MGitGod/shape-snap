# Shape Snap

グリッドに吸着する四角・円・多角形を、クリックと単独キーだけで置いて、動かして、変形して、書き出すブラウザ用の描画ツールです。
ドラッグ、同時押し（Shift・Ctrl・Alt）、ダブルクリック、ホバーだけで使う操作は一つもありません。

**すぐに使う:** https://mgitgod.github.io/shape-snap/ （インストールは要りません。作品は、使っているブラウザの中に保存されます）

**Windows のアプリ:** [ダウンロード](https://github.com/MGitGod/shape-snap/releases/latest) （署名をしていないので、Windows の警告が出ることがあります。進め方はダウンロードのページにあります）

## このツールを作った理由

作者は指が不自由で、同時押しやドラッグなどの操作が困難です。高機能な作図アプリの多くはその操作を前提にしているため、クリックと単独キーだけで使えるこのツールを作りました。
同じような不便を感じているほかの人の役にも立てば、うれしく思います。

## 起動

```
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。作品は自動で保存され、リロードしても戻ります。

### デスクトップアプリ（Windows）

ブラウザなしで起動できるアプリにもできます（Tauri v2）。開発中の起動は `npm run app:dev`、配布用のビルドは `npm run app:build` です。
Rust と Visual Studio Build Tools が要ります。くわしくは [docs/desktop.md](docs/desktop.md) を見てください。

## できること

- 四角・円・多角形をカーソルの位置（グリッドの点）に置く
- 図形をクリックで選び、何もない点をクリックするとそこへ動く
- つまみは 3 種類。辺（四角）は辺の幅を、角（少し大きい四角）は 2 方向を一度に、点（丸）は頂点を動かす。クリックでつかみ、次のクリックか矢印で動かす
- 多角形の辺や点を動かすと「自由な形」になる（Z で戻せる）
- 複数選択すると、揃える・間隔をそろえる操作が設定パネルに出る
- ガイド（キャンバスいっぱいの線）に吸着できる
- 重なった図形は、同じ点をもう一度クリックすると奥のものに切り替わる
- 設定パネルで位置・大きさ・回転・色・線を変える
- 連続配置（A）: 選んだ図形を、個数・間隔・だんだん小さくする割合・回転の増分を決めて並べる。元の図形（実線）を直すと複製（点線）も全部変わる
- 対称（X）: 左右・上下・上下左右・回転で複製する。軸のつまみ（ひし形）をつかんで別の点をクリックすると軸が動く
- グループ（G）: 2 個以上選んでまとめ、1 個の図形として動かす。入れ物は入れ子にできる（連続配置をグループにする、グループを連続配置にする）
- 解く・ばらす（U）: グループを元の図形に戻す。連続配置・対称は複製を独立した図形にする（Z で戻せる）
- 足す・抜く（T）: 選んだ図形を「抜く図形」にすると、それより奥にある図形をくり抜く（もう一度 T で足す図形に戻る）。抜く図形は、ふつうの表示では斜線と点線の輪郭で描き、図形リストに「抜く」の札が付く。元の図形は残るので、あとから位置や大きさを直せる
- 結合を表示（3）: 足す・抜くを一つの輪郭にまとめた結果をキャンバスに出す。もう一度 3 で元の表示に戻る。表示している間も、元の図形を選んで直せる。開いた線は結合に入らず、そのまま線として描く
- SVG、PNG、作業ファイル（JSON）に書き出す。書き出しの「一つの輪郭にまとめる」を入れると、足す・抜くをまとめた輪郭で書き出す（抜く図形があれば初期値は入）。切ると抜く図形は書き出されない

## キー

| キー | はたらき |
|---|---|
| R / C / P | 四角 / 円 / 多角形を置く |
| Q / E | 前の図形 / 次の図形を選ぶ |
| W | 次のつまみをつかむ |
| M | 複数選択の入・切 |
| 矢印 | 選んだ図形（つかんだつまみ）を 1 グリッド動かす。何も選んでいないときは表示を動かす |
| Space | カーソルの位置へ動かす |
| F / B | 一つ手前へ / 一つ奥へ |
| D | 複製 |
| A / X | 連続配置 / 対称にする |
| G / U | グループにする / 解く・ばらす |
| Delete / Backspace | 消す |
| Z / Y | 取り消す / やり直す |
| H / K / O | 隠す・出す / ロック / ソロ |
| 0 | 全体表示 |
| 1 / 2 | グリッドを細かく / 粗く |
| , / . | 縮小 / 拡大 |
| V | 回転（入っている間は矢印で 15° / 1° ずつ回す。もう一度 V か Esc で終える） |
| N | 塗りなし（線が無ければ線を付ける） |
| J | 自由な形に変える |
| T | 足す・抜くを切り替える |
| 3 | 結合の表示の入・切 |
| - / I | 横 / 縦のガイドをカーソルの位置に足す |
| Tab | 操作する場所（キャンバス・図形リスト・設定）を切り替える |
| Esc / 右クリック | つかむのをやめる、選択を外す |

### キーを変える

道具の帯の右にある「キー」を押すと、「キーの設定」が開きます。

- 変えたい行のキーのボタンを押し、「新しいキーを押してください」と出たら、使いたいキーを 1 つ押します。やめるときは Esc。
- 割り当てられるのは、英字・数字・`, . / - ; ' [ ] \ =` と `` ` `` の 1 文字のキーです。それ以外のキー（F1、Home など）は「このキーは使えません」と出ます。
- すでにほかの操作が使っているキーを選ぶと、2 つの操作のキーが入れ替わります（「円」と入れ替えました、と出ます）。どの操作もキーが無い状態にはなりません。
- Esc、Enter、Tab、矢印、Delete、Backspace、Space は「固定」で、変えることも、ほかの操作に割り当てることもできません。
- 変えた行には「初めに戻す」が出ます。「全部を初めに戻す」で全部を初期に戻せます。
- 設定はこのブラウザ（アプリ）に保存され、道具の帯、画面下の案内、設定パネルのボタンの札にも反映されます。
| マウスのホイール | 拡大・縮小（設定パネルの上ではスクロール。値は変わらない） |

数値の欄は、クリックして数字を打つと、打つたびに反映されます（Enter や別の場所のクリックで丸めて確定）。

## テスト

```
npm run typecheck   # 型の検査
npm test            # 単体テスト（Vitest）
npm run build       # 型の検査 + 本番ビルド
npm run e2e         # ブラウザでの通しテスト（Playwright、開発サーバーを自動で起動）
```

`tests/promises.test.ts` と `e2e/promises.spec.ts` が、操作の約束（ドラッグ・同時押しを使わない、ボタンと行は高さ 40px 以上、
ページ全体がスクロールしない、明るい表示と暗い表示のどちらでも文字が読める）を守っているかを確かめます。
