## 分かっている弱い点

- 自動保存に失敗したときの帯は実装してあるが、画面のテストが無い。
- 設定パネルで数字キーを押して数値入力を始める動きは、画面のテストが無い。
- つまみは、図形を回転させても画面に対してまっすぐな四角のまま（位置は正しい）。
- ビルドの直後に `npm run e2e` を走らせると、開発サーバーの起動待ちで数件が時間切れになることがある。もう一度走らせると通る。

## 使う人に確かめてもらうこと

`npm run dev` で起動し、http://localhost:5173 を開く。

1. `R` `C` `P` で図形が出る位置は分かりやすいか。
2. 図形を選んで、何もない点をクリックすると動く。意図せず動いてしまわないか。
3. つまみをクリックでつかみ、行き先をクリックして変形する。つまみは狙いやすい大きさか。
4. `W` でつまみを順につかむ。`Q` `E` で図形を順に選ぶ。キーの位置は押しやすいか。
5. `Tab` で図形リストと設定に移り、矢印キーで値を変える。迷わないか。
6. スライダーの上でホイールを回して値を変える。動く量はちょうどよいか。
7. ホイールでの拡大縮小の速さはちょうどよいか。
8. 画面下の「今使えるキー」は役に立つか。足りない案内はないか。
9. `書き出し` で SVG と PNG を保存し、ほかのアプリで開いて形が合っているか。
