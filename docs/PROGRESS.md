## 計画から外れた点・決めたこと

- 2026-11-13: 座標の単位を「グリッド何個分」から「単位（SVG の px）」に変えた。グリッドを細かくしたときに図形の大きさが変わらないようにするため。設計書の 5 章と 10 章を直した。
- 2026-11-13: 多角形の辺を動かすと「自由な形」（閉じた直線の path）に変わる。多角形は辺の数と半径で形が決まり、一つの辺だけを動かした形を表せないため。
- 2026-11-13: キャンバスは、暗い表示でも明るい紙の色にした（`src/styles.css` の `.stage`）。初期の塗りの色が暗く、暗いキャンバスでは図形が見えなかったため。オーケストレーターが直した。
- 2026-11-13: 図形リストの行を 48px、行の中のボタンを 40px にした。40px の約束を満たすため（Task 10 の検査で見つかった）。
- 2026-11-13: `src/io/session.ts` を足した（計画に無いファイル）。作品の読み込み、400ms の自動保存、作品の操作をまとめたもの。
- 2026-11-13: 確認用のサブエージェントと、最後の全体レビューは立てていない（消費を抑えるため）。全体レビューを足すなら Opus を使うことになるので、使う人に確認してから。

- 2026-11-14: 画面のテストは 1 本ずつ走らせる（`playwright.config.ts` の `workers: 1`）。並列だと開発サーバーの応答待ちで時間切れになるため。
- 2026-11-14: 計画の「等間隔」の例の数値が誤っていた（正しくは minX が 0、100、200）。実装とテストは式どおり。
- 2026-11-14: パネルの「ガイドを足す」ボタンは、カーソルがキャンバスに無いとき、選んだ図形の中心（無ければ画面の中央）に引く。オーケストレーターが直した。

- 2026-11-14: 拡大縮小（`,` `.`）は、選んだ図形を一つの絵として扱う。全体の外枠の左上を動かさず、図形も隙間も同じ割合で変わる。前は図形ごとに自分の中心で変えていて、隙間が変わらなかった（使う人の指摘）。オーケストレーターが直した。

## 分かっている弱い点

- 道具の帯は幅 1280px で 2 段に収めた（ボタンの余白と文字を詰めた）。幅 1024px での段数は確かめていない。
- 線を選んだとき、設定パネルは色の欄が上にあり、「曲線にする」「閉じる」「丸みの強さ」は下へスクロールしないと見えない（`S` キーは効く）。
- 図形を置いたとき、座標が `-0` になることがある（保存すると `0` になる。動きには影響しない）。
- 暗い表示のスクリーンショットは、段階 1.5 では目で確かめていない（テストは通っている）。

- 自動保存に失敗したときの帯は実装してあるが、画面のテストが無い。
- 設定パネルで数字キーを押して数値入力を始める動きは、画面のテストが無い。
- つまみは、図形を回転させても画面に対してまっすぐな四角のまま（位置は正しい）。
- ビルドの直後に `npm run e2e` を走らせると、開発サーバーの起動待ちで数件が時間切れになることがある。もう一度走らせると通る。

## 使う人に確かめてもらうこと

`npm run dev` で起動し、http://localhost:5173 を開く。

1. `L` を押してグリッド点を順にクリックし、`Enter` で確定する。迷わず線が引けるか。
2. 引いている途中の表示（青い線、最初の点の二重の輪、次の点までの点線）は分かりやすいか。
3. 右クリックで一つ戻る、`Esc` でやめる、は使いやすいか。
4. ジグザグを引いて `S` を押す。思ったような波になるか。
5. 設定の「丸みの強さ」を動かす。変わり方はちょうどよいか。
6. 曲線の点（丸いつまみ）をつかんで別のグリッド点をクリックする。曲線がついてくるか。
7. 点をつかんで `/` を押すと、その点だけ尖る。使う場面はあるか。
8. 辺のつまみをつかんで `Enter` で点を足す。点をつかんで `Delete` で点を消す。分かりやすいか。
9. 円を置いて `J` を押し、点を動かして形を崩す。円らしさは保たれているか。
10. 線を選んだとき、設定パネルで「曲線にする」「閉じる」「丸みの強さ」が下のほうにある。上に移したほうがよいか。
11. 道具の帯のボタンを詰めて 2 段にした。文字は小さすぎないか。
