## 分かっている弱い点

- デスクトップ版の実行ファイルの名前が `app.exe`（インストーラーとウィンドウの題は `Shape Snap`）。
- デスクトップ版は署名していないので、Windows が「不明な発行元」と出すことがある。
- デスクトップ版の保存（保存先を選ぶ窓と書き込み）は、自動のテストが無い（SVG の保存は、2026-11-25 に使う人の操作で確かめた）。

- Paper.js を足して、ビルド後のメインのファイルが約 626kB（gzip 206kB）になった。
- 抜く図形は「奥にある全部の図形」をくり抜く。特定の図形だけをくり抜く指定はできない（重なり順で調整する）。

- 図形リストの入れ物の行は、幅が足りず `連続配置 1…` と途中で切れる（`×5` が見えない）。
- 入れ物の中の図形は個別に選べない。直すには `U` で解く必要がある（解くと連続配置ではなくなる）。

- 道具の帯は幅 1280px で 2 段に収めた（ボタンの余白と文字を詰めた）。幅 1024px での段数は確かめていない。
- 図形を置いたとき、座標が `-0` になることがある（保存すると `0` になる。動きには影響しない）。
- 暗い表示のスクリーンショットは、段階 1.5 では目で確かめていない（テストは通っている）。

- 自動保存に失敗したときの帯は実装してあるが、画面のテストが無い。
- 設定パネルで数字キーを押して数値入力を始める動きは、画面のテストが無い。
- つまみは、図形を回転させても画面に対してまっすぐな四角のまま（位置は正しい）。
- ビルドの直後に `npm run e2e` を走らせると、開発サーバーの起動待ちで数件が時間切れになることがある。もう一度走らせると通る。
