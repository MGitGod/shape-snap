# スライダー上でのペインスクロール

## Global Constraints

- ホイールでスライダー・数値入力の値を変更しない。右ペインの通常のスクロールは維持する。
- クリック・数値入力・単独キーの既存操作を維持する。ドラッグや同時押しを追加しない。
- 依存追加、無関係な改修、git push はしない。

## File Structure

- `src/ui/SliderField.tsx`: 共通のスライダー・数値入力。
- `e2e/panels.spec.ts`: ホイール、キー、クリック、取り消しの検証。
- `docs/design.html`: 現在の操作仕様。
- `docs/PROGRESS.md`: 指揮担当が検証後に更新。

## Task 1: ホイールによる意図しない変更を止める

### Interfaces

`SliderFieldProps` と呼び出し側は変更しない。共通部品の全利用箇所でホイールを値の変更に使わない。

### 決まり

- 行・スライダー・数値入力（フォーカス中を含む）上のホイールで文書が変わらないこと。
- スライダー上から右ペインを上下にスクロールできること。
- 既存のホイール増減を前提とするテストは、クリックかキーで同じ目的を検証する。
- 設計書5章のホイール操作を新しい仕様に合わせる。過去の実装計画は履歴として残す。

### テスト

先に回帰テストを書き、既存実装で期待どおり失敗することを確認してから修正する。
`npm run typecheck`、`npm test`、`npm run e2e`、`npm run build` が通ること。

### 完了条件

上記の検証を通して実装・テスト・設計書をコミットする。変更ファイル、コマンドと結果、計画からの逸脱、気になった点を報告する。
