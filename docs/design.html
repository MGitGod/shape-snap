Shape Snap 設計書

図形を組み合わせてロゴや複雑な図形を作る、クリックと単独キーだけの作図ツール ／ 2026-11-13 ／ 名前は仮
このツールの約束
  • ドラッグを使わない。押しながら動かす操作は一つもない。
  • 同時押しを使わない。Shift・Ctrl・Alt との組み合わせは一つもない。
  • ダブルクリックを使わない。時間に追われる操作は一つもない。
  • 使う操作は、単独キー、カーソル移動、左クリック、右クリック、ホイール、矢印キーの連打だけ。
  • すべての位置はグリッドに吸着する。狙いが少しずれても、近いグリッド点に入る。

1. 目的と範囲

高機能な作図アプリは、同時押しとドラッグを前提にしている。指が不自由だとベジェ曲線が引けず、図形の変形も難しい。このツールは、簡単な図形をグリッドに置いて組み合わせることで、同じ結果に届くようにする。

  • 作るもの: ロゴ、アイコン、模様など、図形の組み合わせでできる絵。
  • 書き出し: SVG（主）と PNG。
  • 動かし方: まずブラウザで開くアプリとして作る。ネット接続は要らない。使い勝手が固まったら、同じ中身をデスクトップアプリに包む。

2. 画面の配置

  • 道具の帯のボタンは、キーと同じ動きをする。キーでもクリックでも同じ結果になる。
  • ボタンと行は大きめに作る（高さ 40px 以上）。狙いやすさを優先する。
  • カーソルを乗せただけで出る表示（ホバー専用の操作）は使わない。

3. 操作の基本

図形を置く

  1. R を押すと、カーソルに一番近いグリッド点に正方形が出る。カーソルがキャンバスの外なら中央に出る。
  2. 出た図形は選ばれた状態になる。すぐに設定のスライダーや矢印キーで直せる。

図形を選ぶ

  • 図形をクリックする。
  • 重なっている場所は、同じ位置をもう一度クリックすると下の図形に移る。間を空けてよい（速さは問わない）。
  • Q で前の図形、E で次の図形に移る。カーソルを使わない。
  • 右クリックか Esc で選択を外す。

図形を動かす

  • クリックで動かす: 図形を選び、何もないグリッド点をクリックすると、図形の基準点がそこへ移る。
  • カーソルの位置へ動かす: Space を押すと、カーソルに一番近いグリッド点へ移る。行き先に別の図形があっても動かせる。
  • 矢印キーで動かす: 1 回押すと 1 グリッド動く。
  • 基準点は「中心」と「四隅」から選べる。初期値は中心。

図形を変形する（つまみ）

図形を選ぶと、頂点と辺の真ん中に四角いつまみが出る。つまみは引っ張らない。クリック 2 回で動かす。

  1. つまみをクリックすると、そのつまみを「つかんだ」状態になる（色が変わる）。
  2. 行き先のグリッド点をクリックすると、つまみがそこへ動く。
  3. 右クリックか Esc で、つかむのをやめる。
  • つかんでいる間は、矢印キーでも 1 グリッドずつ動かせる。
  • 図形を選んでいる間、W で次のつまみをつかむ。小さなつまみをカーソルで狙わなくてよい。
  • つまみは大きめに作る（画面上で 14px 以上、クリックが効く範囲は 24px 以上）。拡大縮小しても大きさは変わらない。
  • 幅・高さ・回転は、設定のスライダーか数値でも変えられる。
図形辺の真ん中のつまみ 1頂点のつまみ 2
四角その辺が平行に動く（正方形が長方形になる）その角だけが動く（突き出した形になる）
多角形（三角形など）その辺が平行に動く（動かすと「自由な形」に変わる）その角だけが動く
円上下左右の 4 つ。動かすと楕円になるなし。「点に変える」で 8 個の点を通る曲線に変えると、点を動かせる
線なしその点だけが動く
  • 辺のつまみは、辺に垂直な向きにだけ動く。行き先のクリックが斜めにずれても、垂直な向きの分だけを使う。回転した図形でも同じ。
  • 辺のつまみだけを使っている間、四角は四角のまま、円は楕円のまま。幅や高さのスライダーも連動する。
  • 多角形は「辺の数と半径」で形が決まるので、一つの辺だけを動かすと「自由な形」に変わる。辺の数や半径のスライダーは使えなくなる。
  • 頂点のつまみを動かすと、図形は「自由な形」（線で囲んだ形）に変わる。幅・高さ・角の丸みのスライダーは使えなくなる。変わる前に、キーの案内に一言出す。Z で戻せる。

移動と変形の分け方

「つまみをつかんでいるかどうか」だけで分かれる。モードの切り替えはない。

矢印キー移動変形
Space移動（カーソルの位置へ）変形（つまみをカーソルの位置へ）
右クリック ／ Esc選択を外すつかむのをやめる（図形は選んだまま）

キャンバスを見る

  • ホイールで拡大縮小する。カーソルの位置を中心に拡大する。
  • 何も選んでいないとき、矢印キーで表示位置が動く。
  • 0 で全体が収まる表示に戻る。

5. スライダーと数値入力

すべての値に、スライダーと数値の欄を並べて置く。どちらで変えても同じ結果になる。

  • クリック: スライダーの上の好きな位置をクリックすると、つまみがそこへ飛ぶ（つまみを引っ張らなくてよい）。
  • ホイール: カーソルをスライダーに乗せてホイールを回すと増減する。
  • キー: Tab で設定に移り、↑ ↓ で項目を選び、← → で増減する。数字を打つと数値入力になり、Enter で確定する。
  • 単位: 大きさと位置は「単位」で表す（1 単位 = 書き出した SVG の 1px）。スライダーの刻みはグリッドの間隔に合わせる。グリッドの間隔を変えても、置いた図形の大きさは変わらない。細かく合わせたいときは、グリッドを細かくする（1）。
対象変えられる値
四角幅、高さ、角の丸み、回転
円横の半径、縦の半径、回転、「点に変える」ボタン（段階 2）
多角形辺の数、半径、星形にする割合、回転
線丸みの強さ、閉じる ／ 開く
共通位置（横・縦）、塗りの色、線の色、線の太さ、不透明度
グリッド間隔、表示の入り切り、吸着の入り切り

色は、よく使う色の見本を並べてクリックで選ぶ。色コード（#2f6fde など）の入力と、色相・彩度・明るさのスライダーも用意する。

6. 線と曲線

線を引く

  1. L を押す。
  2. グリッド点を順にクリックする。クリックするたびに線が伸びる。
  3. 間違えたら右クリックで一つ戻す。
  4. Enter で確定する。最初の点をクリックすると、閉じた形として確定する。

曲線に変える

  • S か「曲線に変更」ボタンで、線全体が滑らかになる。もう一度押すと直線に戻る。
  • 「丸みの強さ」スライダーで、ゆるい波からきつい波まで変えられる。
  • 点のつまみをつかんで「この点は角のまま」を入れると、そこだけ尖らせられる。
  • 曲線にしたあとも、点を動かせば曲線がついてくる。ベジェ曲線のハンドルは出さない。
  • 計算は、点を通る曲線（Catmull-Rom）を SVG の三次ベジェ曲線に直して描く。

7. 図形リスト

図形が増えると、重なった図形をカーソルで狙うのが難しくなる。そこで、全図形を右側に一覧する。

  • 一行が一つの図形。上にあるほど手前に描かれる。
  • 行をクリックするか、Q E で選ぶ。選ぶとキャンバス上でも強調される。
  • 各行に「表示」「ロック」「役割（足す ／ 抜く）」の切り替えがある。キーは H K T。
  • ロックした図形はクリックに反応しない。下絵や、置き終えた図形の誤操作を防ぐ。
  • ソロ表示（O）は、選んだ図形以外を薄くして触れなくする。もう一度押すと戻る。
  • 名前は自動で付く（四角 1、円 2）。変えたいときだけ変える。
  • グループ、連続配置、対称コピーは、中身を畳める親の行になる。

8. 連続配置・対称コピー・グループ

3連続配置

図形を選んで A。同じ図形が並ぶ。個数、横の間隔、縦の間隔、一つごとの拡大率、一つごとの回転をスライダーで変える。

3対称コピー

図形を選んで X。左右、上下、回転（何回対称か）から選ぶ。軸の位置はグリッド点のクリックで決める。

3グループ

複数選んで G。まとめて動かせる。必須ではない。必要なときだけ使う。

  • 例: 正方形を置く → A → 個数 5、横の間隔 3、拡大率 0.85。左から右へ、だんだん小さくなる正方形が 5 個並ぶ。
  • 連続配置と対称コピーは「元の図形 + 複製の規則」として持つ。元の図形を直すと、複製も全部変わる。個数や間隔はあとからいつでも変えられる。
  • 一つずつ別々に直したくなったら、「ばらす」で独立した図形に変える。
  • 連続配置の上に対称コピーを重ねられる（例: 並べた正方形を 6 回対称にして輪にする）。

9. 結合と書き出し

足す・抜くの役割

  • 図形は置いた時点では「足す」。T で「抜く」に切り替える。抜く図形は点線で表示する。
  • 「結合を表示」を入れると、合体後の輪郭をその場で確かめられる。元の図形は残るので、位置や大きさを直すと輪郭もすぐ変わる。
  • 結合は、グループごとにも、全体にもかけられる。色が違う部分は別のグループにして、それぞれ結合する。
  • 線（閉じていない線）は、太さを持った帯の形に直してから結合する。
  • 結合の計算には Paper.js の図形演算を使う。自前では作らない。

書き出し

形式中身使いどころ
SVG（結合する）結合した輪郭だけ。グリッドは入らないロゴとして使う
SVG（結合しない）図形を置いたままほかの作図アプリで続きを直す
PNG大きさを選べる（512、1024、2048、数値入力）。背景は透明か色画像として使う
作業ファイル（.json）図形、グリッド、複製の規則をすべて含むあとで続きを作る、別のパソコンへ移す

書き出す範囲は、図形全体がちょうど収まる枠か、キャンバス全体から選ぶ。余白はスライダーで変える。

10. データの形

画面とは別に、絵の中身を一つのデータとして持つ。段階 3 と 4 の機能が入る場所は、段階 1 から用意しておく。

Document
  version        データの版（古い作業ファイルを読むために使う）
  grid           { size, visible, snap }
  nodes[]        並び順 = 重なり順

Node（共通）
  id, name, visible, locked
  role           "add" | "subtract"      ← 段階 4 で使う。段階 1 から持つ
  transform      { x, y, rotation }      x, y は図形の中心。単位は SVG の px

Node の種類
  rect           { width, height, cornerRadius }
  ellipse        { rx, ry }
  polygon        { sides, radius, starRatio }
  path           { points[{x, y, corner}], closed, smooth, tension }
  group          { children[] }                               ← 段階 3
  repeat         { child, count, dx, dy, scaleStep, rotateStep }   ← 段階 3
  mirror         { child, mode, axis, count }                 ← 段階 3

style（図形ごと）
  fill, stroke, strokeWidth, opacity
  • 位置と大きさは「単位」（書き出した SVG の px）で持つ。グリッドは吸着先を決めるだけで、間隔を変えても図形は変わらない。
  • 連続配置と対称コピーの複製は、データには持たない。描くときに規則から作る。
  • つまみはデータには持たない。図形の種類と値から、描くときに位置を計算する。辺のつまみは幅・高さ・半径と位置を書き換える。頂点のつまみは、rect・polygon を path に変えてから点を動かす。円の「点に変える」は、ellipse を 8 点の滑らかな path に変える。
  • すべての変更は「命令」（図形を足す、動かす、値を変えるなど）として記録する。取り消しとやり直しは、この記録をたどる。

11. プログラムの構成

使う技術: TypeScript、Vite、React、Vitest（単体テスト）、Playwright（画面のテスト）。結合の計算だけ Paper.js。

部分役割頼る相手
core/modelデータの形と、その検査なし
core/commands命令の実行、取り消し、やり直しmodel
core/geometry吸着、当たり判定、つまみの位置と動かし方、曲線化、複製の展開、外枠の計算model
core/boolean結合とくり抜き（段階 4）geometry、Paper.js
inputキーとマウスの入力を命令に直す。今の状態（選択、つまみをつかんでいる、線を引いているなど）を持つcommands
renderデータを SVG として描く。選択の強調、吸着先の印もここgeometry
ui道具の帯、図形リスト、設定、キーの案内input、commands
io自動保存、作業ファイルの読み書き、SVG・PNG の書き出しmodel、render
  • core は画面を知らない。計算だけなので、自動テストで確かめやすい。
  • 画面に描く SVG と、書き出す SVG は、同じ render の関数から作る。画面と書き出しがずれない。
  • キーの割り当ては一つの表（keymap）にまとめる。画面下のキーの案内も、設定画面の割り当て変更も、同じ表から作る。
  • デスクトップアプリにするときは、この中身を Tauri で包む。変わるのは io（ファイルの保存先）だけ。

12. 保存と失敗時の動き

  • 自動保存: 操作のたびに、ブラウザの中（IndexedDB）へ保存する。保存の操作は要らない。次に開くと続きから始まる。
  • 作品の一覧: 複数の作品を持てる。開始画面で選ぶ。
  • 控え: ブラウザのデータを消すと作品も消える。そのため、作業ファイル（.json）の書き出しを目立つ場所に置く。
  • 保存に失敗したとき: 画面の上に帯で知らせ、作業ファイルの書き出しを勧める。作業は止めない。
  • 数値がおかしいとき: 範囲の外や数字でない入力は、元の値に戻し、欄を赤くして知らせる。
  • 作業ファイルが壊れているとき: 読み込まず、どこがおかしいかを表示する。今の作品は上書きしない。
  • 結合に失敗したとき: 結合の表示だけを外し、原因の図形をリストで示す。図形のデータは変えない。

13. テスト

  • 単体テスト（core）: 吸着、当たり判定、つまみの動き（回転した図形を含む）、曲線化、複製の展開、命令の取り消しとやり直し、データの検査。
  • 画面のテスト: 「R を押す → 点をクリック → 書き出した SVG に四角がその位置にある」のように、キーとクリックだけで通す。ドラッグと同時押しを一度も使わずに全機能が使えることを、テストで保証する。
  • 書き出しの検査: 書き出した SVG を読み直し、画面と同じ形になっているかを比べる。
  • 各段階の終わり: 実際に使ってもらい、使いにくい点を直してから次の段階へ進む。

15. 今回は作らないもの

  • 文字（テキスト）の入力と、フォントの扱い。
  • 写真や画像の読み込み（下絵としての読み込みは、あとで足す候補）。
  • グラデーション、影、ぼかし。
  • ベジェ曲線のハンドルを直接動かす操作。
  • 複数人での同時編集、ネット上への保存。

16. 使ってみての改善（2026-11-14）

段階 1 を使った感想から決めたこと。上の章と食い違う所は、この章が優先する。

角と辺をグリッドに乗せる

  • 多角形は「中心と半径」ではなく「幅と高さの箱」に収まる形で持つ。三角形は、置いた時点で 3 つの角がグリッドに乗る。
  • クリック移動と矢印キーは、図形の外枠をグリッドの線に合わせる（基準点「自動」）。ずれていた図形も、動かすと線に乗る。
  • つまみを矢印キーで動かすと、その向きで次のグリッドの線まで動く。

つまみ（3 章の表を置き換える）

図形つまみ動かしたとき
四角辺 4 個（四角）+ 角 4 個（大きい四角）辺: その辺が動く。角: 大きさが変わる。四角のまま
円辺 4 個 + 外枠の角 4 個（8 方向）辺: 楕円になる。角: 横と縦の半径が変わる
多角形角（丸）と辺（四角）が交互角: その角がクリックしたグリッド点へ動く。辺: 両端が同じ量だけ動く。どちらも「自由な形」に変わる
自由な形多角形と同じ同じ

四角の角だけを突き出したいときは、J（自由な形に変える）を押してから角を動かす。円を自由な形に変えるのは段階 2。

足したキー

キー動き
, .縮小 ／ 拡大（選んだ図形全体の外枠の、大きい辺がグリッド 1 個分ずつ変わる。外枠の左上は動かない。複数選んでいるときは、図形の間の隙間も同じ割合で変わる。押し続けられる）
V回転の状態に入る・出る。入っている間、← → で 15°、↑ ↓ で 1° ずつ回る
N塗りなしの切り替え。線が無い図形には、元の塗りの色で線を付ける
J自由な形に変える（四角・多角形）
-横のガイドを、カーソルの位置に引く
I縦のガイドを、カーソルの位置に引く

複数選択のときの設定

  • 揃える: 左、左右の中央、右、上、上下の中央、下。
  • 間隔: 横の間隔と縦の間隔のスライダー。一番手前（左か上）の図形は動かず、残りが指定した間隔で並ぶ。
  • 等間隔: 両端の図形は動かさず、間を同じにする。

ガイド

  • キャンバスいっぱいの線。吸着先の候補になる（グリッドに吸着を切っていても効く）。
  • グリッドのパネルに一覧があり、一本ずつ消せる。パネルのボタンから足すと、選んだ図形の中心（無ければ画面の中央）に引く。
  • 書き出しには出ない。取り消せる。

見た目と入力

  • グリッドは薄い水色の線で描く。5 本ごとに少し濃くする。点の表示はやめた。
  • 吸着先には輪と十字の印を出し、画面下の右端に座標を出す。
  • 数値の欄は、Enter を押さなくても、打った瞬間に反映する。
  • 色の欄は設定の一番上に置き、「なし」を見本の先頭に置く。
  • キャンバスは、暗い表示でも明るい紙の色にする。

17. 線と曲線の決まり（段階 2、2026-11-14）

6 章の内容を実装したときに決めたこと。食い違う所は、この章が優先する。

キー動き
L線を引き始める。グリッド点を順にクリックする（Space でもカーソルの位置に点を足せる）
Enter線を確定する。辺のつまみをつかんでいるときは、その辺の真ん中に点を足す
右クリック ／ Backspace ／ Z引いている途中の点を一つ戻す
Esc引くのをやめる（絵は変わらない）
S選んだ線・自由な形を、曲線にする ／ 直線に戻す
/つかんでいる曲線の点を、角にする ／ 丸める
Delete点をつかんでいるときは、図形ではなくその点を消す
J円も自由な形に変えられる（8 個の点を通る曲線になる）
  • 最初の点をクリックすると、閉じた形（自由な形）として確定する。点が 3 個以上のとき。
  • 線は、塗りなし・線の太さ 4 で始まる。閉じた形は、塗りありで始まる。設定の「閉じる」「開く」で切り替えられる。
  • 曲線は、全部の点を通る。丸みの強さは 0（直線と同じ）から 1 まで。初期値は 0.5。
  • 曲線のつまみは点だけ（辺のつまみは出ない）。角にした点は、ひし形で表示する。
  • 線を引いている間は、図形の選択や移動はできない。拡大縮小、表示の移動、グリッドとガイドは使える。
  • 道具の帯は、幅 1280px で 2 段に収めた（見出しと「作品」「書き出し」が 1 段目）。

18. 連続配置・対称・グループの決まり（段階 3、2026-11-14）

8 章の内容を実装したときに決めたこと。食い違う所は、この章が優先する。

キー動き
A選んだ図形を連続配置にする（最初は 5 個、横に並ぶ）。複数選んでいれば、先にグループにしてから並べる
X選んだ図形を対称にする（最初は左右）
G選んだ 2 個以上の図形をグループにする
Uグループを解く。連続配置と対称は、複製を独立した図形にばらす
  • 仕組み: 図形を「入れ物」で包む。複製はデータに持たず、描くときに規則から作る。元の図形（実線の枠）のつまみや色を変えると、複製（点線の枠）も全部変わる。
  • 連続配置の設定: 個数（2〜50）、横の間隔、縦の間隔、大きさの変化（0.5〜1.5。1 より小さいとだんだん小さくなる）、回転の増分。
  • 対称の設定: 種類（左右、上下、上下左右、回転）、回転の数（2〜36）、軸の位置。軸は、ひし形のつまみをつかんでグリッド点をクリックしても動かせる。
  • 入れ子: 連続配置を対称で包む、グループを連続配置にする、ができる。
  • 選び方: 入れ物は 1 個の図形として選ぶ。中の図形を個別には選べない。直したいときは U で解く。
  • 吸着: 入れ物を動かすときは、元の図形の外枠をグリッドに合わせる（複製の外枠ではない）。
  • 書き出し: 複製も全部、独立した図形として SVG に出る。
  • 設定パネルの並び: 図形ごとの設定（スライダー）が一番上、次に色、最後に操作のボタン。

19. 結合とくり抜きの決まり（段階 4、2026-11-14）

9 章の内容を実装したときに決めたこと。食い違う所は、この章が優先する。

キー動き
T選んだ図形の役割を、足す ／ 抜く で切り替える
3結合を表示する ／ 元の表示に戻す
  • 抜く図形は、それより奥にある図形をくり抜く。 手前にある図形には影響しない。重なり順（F B）で、どれをくり抜くかが変わる。
  • 同じ見た目（塗り・線・太さ・不透明度）で、重なり順が続いている図形は、一つの輪郭に合体する。 間に違う色の図形が挟まると、別々の輪郭になる。
  • 曲線はベジェ曲線のまま保つ。連続配置や対称の複製も結合に入る。
  • 開いた線は結合に入らない。 線のまま書き出す（9 章の「帯の形に直す」はやめた）。結合したいときは、線を閉じて自由な形にする。
  • 抜く図形は、ふつうの表示では赤い斜線と点線の輪郭で描く。図形リストに「抜く」の札が付く。
  • 結合を表示している間も、元の図形を選んで動かしたり変形したりできる。結果はその場で変わる。
  • 書き出し: 「一つの輪郭にまとめる」のチェックボックス。抜く図形が 1 個でもあれば、最初から入っている。チェックを外すと、抜く図形は書き出されない。
  • 結合に失敗したときは、結合の表示を切り、原因の図形を選んで、名前を帯で知らせる。絵のデータは変わらない。
  • 計算には Paper.js を使う（アプリの大きさが約 200kB 増えた）。
